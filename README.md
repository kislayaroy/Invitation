# Invitation

Digital wedding invitation for Shanmuka Sai & Priyanka, rebuilt as a React app from the live site at [shanmuka-priyanka.vercel.app](https://shanmuka-priyanka.vercel.app).

## Features

- Envelope entry video and background music
- Live countdown to the muhurtham
- Parents, venue, and event timeline
- Fun RSVP form with a success modal

## Run locally

```bash
npm install
npm run dev
```

## Customize

Edit `src/data/wedding.js` to change names, dates, venues, media, and RSVP settings.

Optional environment variables:

- `VITE_RSVP_API` — RSVP endpoint
- `VITE_CLIENT_ID` — RSVP client id
